# Voice DAW ― 声を電子楽器に

声をマイクで録音し、ノイズ除去・EQ・ピッチ補正・ボコーダーなどのエフェクトで電子音化し、
鍵盤やパッドで「楽器」として演奏しながら曲を作れる、ブラウザ完結型の音声制作ツールです。

録音 → ノイズ除去 → 音声編集 → 電子音化 → 楽器化 → 演奏 → シーケンサーで曲作り → ミキシング → 書き出し

までを1つのアプリで行えます。**ビルド不要・外部ライブラリ依存なし**の素のHTML/CSS/JavaScript（ES Modules）で作られており、
Node.jsは付属の開発用サーバーやテストを動かすためだけに使います（アプリ自体の実行には不要です）。

---

## 1. インストール（準備）

このアプリはビルド不要です。以下のどちらかで開けます。

### A. すぐ試す（ローカルサーバーを使う）
Node.js が入っていれば、フォルダ内で：

```bash
npm run dev
```

表示された `http://localhost:8080/` を **Microsoft Edge** または **Google Chrome** で開きます。
（`file://` で直接HTMLを開くと、AudioWorkletやマイクの制約でエフェクトや録音が動作しないため、
必ずサーバー経由 **または後述のGitHub Pages** で開いてください。localhost は https:// でなくても
マイクが使える特別な扱いになっています。）

### B. GitHub Pages で公開する
```bash
npm run build
```
`dist/` フォルダの中身をリポジトリのルート（もしくは `docs/`）に置いて GitHub Pages を有効にすれば、
`https://<ユーザー名>.github.io/<リポジトリ名>/` でそのまま動作します。HTTPSなのでマイクも問題なく使えます。

---

## 2. 起動

ページを開くと初回セットアップ画面が表示されます。マイクを選び、「マイクを許可してテスト」を押して、
声を出してメーターが動くか確認してください（ブラウザの許可ダイアログが出たら「許可」を選びます）。

---

## 3. マイク許可

うまくいかない場合は次を確認してください。

- アドレスバー左の鍵/カメラアイコン →「マイク」を「許可」にしてページを再読み込み
- Windowsの「設定 → プライバシーとセキュリティ → マイク」で、ブラウザのアクセスが許可されているか
- 他のアプリ（Zoom, Discordなど）がマイクを使用中でないか
- `http://` の独自ドメインでは動きません。`https://` または `http://localhost` を使ってください

---

## 4. 録音

左メニューの **Record** から、マイクを選んで「● 録音」。一時停止・再開・停止ができ、
録音中は波形とレベルメーター、クリッピング警告が表示されます。テイクは複数保存でき、名前変更・削除も可能です。
録音データは録音中も自動的にIndexedDBへ退避されるため、ブラウザが落ちても「復元する」ボタンで復旧できます。

## 5. ノイズ除去（仕上げ）

テイクの「仕上げ→保存」を押すと、原音の波形が表示されます。無音区間をドラッグして選択し
「選択範囲からノイズ推定」を押すと、その区間をノイズとして学習し除去精度が上がります。
「▶ 原音」「▶ 処理後」で比較しながら、ノイズ除去・EQ・トリム・ノーマライズを調整し、
「ライブラリへ保存」で素材として確定します。

## 6. エフェクト・電子音化

**Effects** パネルの「ワンクリック電子音化」で、素材とプリセット（ロボット、ケロケロ、8bitチップなど）を選んで
即座に電子音化できます。トラックを選んで右側の「トラックFX」を開けば、40種類以上のエフェクトを
ドラッグ&ドロップで自由に組み合わせ、Wet/Dryやパラメータを調整し、プリセットとして保存できます。
パラメータ横の「A」ボタンでタイムライン上にオートメーションカーブを表示・編集できます。

## 7. 楽器化・演奏

**Instruments** パネルには次のモードがあります。

- **Sampler**: 録音した声を鍵盤にマッピングし、Start/End・ループ・ADSRを設定して演奏
- **Voice Synth**: 声とオシレーター(サイン/三角/ノコギリ/矩形/ノイズ)をミックスし、フィルターとLFOで音作り
- **パッド**: 16個のパッドに素材を割り当てて演奏（ライブラリからドラッグ&ドロップ、キー 1234/QWER/ASDF/ZXCV に対応）
- **Voice Chop**: 「こんにちは」→「こ」「ん」「に」「ち」「は」のように自動/手動で音声を分割し、
  素材化・パッド割り当て・タイムライン配置ができます

画面上の鍵盤はマウス操作のほか、PCキーボード（Z=C3 など、画面に表示されるキー配置）やMIDIキーボード（「MIDI接続」ボタン）に対応しています。

## 8. シーケンサーで曲作り

中央のタイムラインに、ライブラリの素材（ダブルクリックまたはドラッグ）やドラムパターンを配置します。
複数トラックの追加・削除・複製・ミュート・ソロ・音量・パンが可能です。**Sequencer** パネルでは
Kick/Snare/Hi-Hat/Clap/Percussion/808 の16/32ステップのドラムパターンを作成・複製できます。
クリップは端をドラッグしてトリム、ドラッグで移動、S キーで再生位置で分割できます。

## 9. ミキシング

**Mixer** パネルでトラックごとの音量・パン・ミュート・ソロを操作し、マスターにはコンプレッサー・
リミッター・オートゲイン（LUFSターゲットへ自動調整）を搭載しています。リアルタイムのLUFSメーターと
ピーク/RMSメーターで確認しながら調整できます。

## 10. 保存

上部の「保存」またはCtrl+Sでプロジェクトをブラウザ内（IndexedDB）に保存します。20秒ごとの自動保存と、
5分ごとの自動バックアップ（最新12件）も行われるため、閉じ忘れてもほぼ復旧できます。「プロジェクト」画面
からは、保存済みプロジェクトの一覧、バックアップからの復元、`.vdaw` ファイルとしての書き出し/読み込み
（トラック・素材・エフェクト・オートメーション・パターンなどを1ファイルに含む独自形式）ができます。

## 11. 書き出し

「⇩ 書き出し」から、マスター全体 / トラックごと / ループ範囲を、WAV(16/24/32bit) ・ MP3(128〜320kbps) ・
OGG ・ WebM(いずれもOpus、ブラウザ標準のMediaRecorderを使用) で書き出せます。書き出し中は進捗バーが表示されます。
歌ってみた素材からのMIDI風ノート抽出（Voice to MIDI）にも対応しています。素材ライブラリの各素材の
「🎼 MIDI化」ボタンから、検出されたノート（音程・長さ）を確認し、標準MIDIファイル(.mid)として書き出せます。

## 12. PWA化

設定画面、または上部の「📲 アプリ化」から、ブラウザの「アプリとしてインストール」機能でインストールできます。
インストール後はタブではなく独立したウィンドウとして起動し、オフラインでも録音・編集・エフェクト・保存・
プロジェクト読み込み・楽器演奏ができます（初回アクセス時に必要なファイルをキャッシュします）。

## 13. Windowsデスクトップからの起動

ブラウザの制約上、Webページから直接デスクトップに `.lnk` ファイルを作ることはできません。設定画面の
「デスクトップから起動する方法」から、以下のいずれかを案内しています。

1. **アプリとしてインストール**（推奨）: Edge/Chromeの「アプリとしてインストール」→インストール時に
   「デスクトップにショートカットを作成する」にチェック
2. インストール後、スタートメニューの「Voice DAW」を右クリック→ファイルの場所を開く→ショートカットをデスクトップへコピー
3. 簡易ランチャー: `.url`（ダブルクリックでブラウザで開く）または `.bat`
   （PowerShellでEdge/Chromeのアプリウィンドウ用ショートカットをデスクトップに作成）をダウンロードして実行

## 開発者向け

```bash
npm run dev      # 開発サーバー（http://localhost:8080）
npm run build    # dist/ に公開用ファイル一式を生成（Service Workerのキャッシュ一覧も自動更新）
npm run preview  # dist/ をローカルサーバーで確認
npm test         # DSP/解析/レンダリングのセルフテスト（Node.jsのみ、ブラウザ不要）
```

依存パッケージはありません（`npm install` は不要です）。MP3書き出し用の [lamejs](https://github.com/zhuker/lamejs)
のみ `src/vendor/lame.min.js` として同梱しています（MITライセンス）。

### 構成
```
src/
├ audio/        AudioContext・マイク入力・FFT・ドラム音源・編集(カット/フェード/タイムストレッチ等)
├ effects/      40種類以上のDSPエフェクト、AudioWorkletチェーン、プリセット
├ recorder/     録音（AudioWorklet）、自動保護・復旧
├ sampler/      Sampler（鍵盤サンプラー）
├ synthesizer/  Voice Synth（声+オシレーターのハイブリッドシンセ）
├ sequencer/    タイムライン全体のオフラインレンダリング（Web Worker）、トランスポート
├ mixer/ timeline/  （タイムライン/ミキサーのUIは src/ui 内）
├ storage/      IndexedDBラッパー（素材・プロジェクト・バックアップ・復旧データ・プリセット）
├ export/       WAV/MP3(lamejs)/OGG/WebM(MediaRecorder) 書き出し
├ midi/         Web MIDI 入力、標準MIDIファイル書き出し
├ analysis/     ピッチ検出(YIN)・BPM推定・無音検出・LUFS・自動音声分割
├ ui/           各画面のUI（録音/ライブラリ/エフェクト/楽器/シーケンサー/ミキサー/LIVE/実験モード 等）
└ pwa/          PWAインストール・Windows導線
```

### ブラウザの制約について（正直な説明）
- Webページから直接デスクトップに `.lnk` を作成することはできません（上記「13」の代替手段で対応）
- OGG書き出しは、ブラウザがOGG/Opusの録音に対応していない場合、自動的にWebM(Opus)にフォールバックし、
  その旨を通知します
- `file://` で直接HTMLファイルを開いた場合、AudioWorkletの読み込みやマイク権限の扱いがブラウザにより
  制限されるため、必ず `npm run dev` のようなサーバー経由、またはGitHub Pages等のHTTPS環境で開いてください
